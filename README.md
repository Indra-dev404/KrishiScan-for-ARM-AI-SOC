# 🌿 KrishiScan

**Offline crop-disease detection and advisory for smallholder farmers.**

KrishiScan identifies tomato leaf diseases from a phone photo, estimates how severe the infection is, and gives the farmer treatment advice in their own language. All of it runs **on the phone, with no internet connection**. It is built for rural areas where connectivity is weak or absent, and for the ordinary Android handsets farmers actually own.

> Built for Problem Statement 1 (offline crop-disease / pest detection & advisory) on Arm devices.

## 📱 The Android app

Point the camera at a leaf, tap **Scan Leaf**, and the app returns:

1. **Diagnosis** — one of 10 tomato classes (9 diseases/pests + healthy), with confidence.
2. **Severity** — the share of the leaf covered by lesions, shown as a coloured Mild / Moderate / Severe chip.
3. **Advice** — what the problem is, what to do now, and how to prevent it.

Two separate on-device pipelines do the work:

| Pipeline | Model | Runtime | Input → output |
|---|---|---|---|
| **Vision** | Distilled TinyCNN student (0.39M parameters, 1.5 MB) | ONNX Runtime Android 1.32.0, Arm CPU | Leaf photo → disease class |
| **Advisory** | Llama 3.2 1B-Instruct (SpinQuant INT4) | **ExecuTorch 1.5.1** LLM runner, Arm CPU | Diagnosis + severity + region + verified facts → advice text |

The photo never reaches Llama. Llama receives text only: the diagnosis, the measured severity, the farmer's region, and a set of verified facts for that disease. It is told to use those facts and nothing else, so it cannot invent a chemical or a dose. If Llama is not available, the app shows the same verified advice as plain text, so the farmer never gets an empty screen.

Also in the app:

- **Severity (OpenCV 4.11)** — segments the leaf and the lesions in HSV colour space and reports lesion area ÷ leaf area.
- **Languages** — English advice is generated by Llama. Hindi and Bengali use translated versions of the same verified advice, because Llama 1B's Bengali output was not reliable enough in testing.
- **Region selector** — eight Indian states, West Bengal by default.
- **Offline by construction** — the app does not request the INTERNET permission, so it cannot reach a network even if one is available.

## 📊 Model results (v1 — tomato, PlantVillage)

Trained and evaluated on the PlantVillage tomato subset (10 classes, stratified 80/10/10 split, fixed seed):

| Model | Role | Test accuracy | Size |
|---|---|---|---|
| MobileNetV2 | Baseline | 99.95% | 9.2 MB |
| EfficientNet-B0 | Teacher | 99.95% | 16.4 MB |
| TinyCNN (0.39M params) | Student, distilled (T=4, α=0.7) — **this is the model in the app** | 99.34% | 1.5 MB |
| TinyCNN INT8 (static) | Quantized student, measured in PyTorch on a desktop CPU | 99.40% | 0.41 MB, 12.6 ms/image |

Grad-CAM sanity check: 6/6 correct predictions with heatmaps localising on the disease lesions.

> ⚠️ **Honest note:** PlantVillage images are controlled laboratory photos: one leaf, plain background, even light. These numbers do **not** establish accuracy in a real field. The 12.6 ms figure is a desktop-CPU measurement of the INT8 model, not a phone measurement.

### Severity pilot

The severity step was checked against 15 PlantVillage photos that were hand-labelled first. The current version (v2) agrees with the hand labels on **10 of 15**. The bands (Mild < 5%, Moderate 5–25%, Severe > 25% of the leaf) are still **proposed**, and the app labels them that way. Known limit: bacterial spot reads close to 0%, because its small dark spots share the leaf's hue.

## ⚠️ Known limitations

- **One crop.** Tomato only, 10 classes.
- **Lab images.** Field accuracy has not been measured.
- **Pests.** One pest class is covered (two-spotted spider mite). A wider pest set (IP102 subset) is future work.
- **Severity** is a pilot on 15 photos, not a validated measure.
- **Llama needs a one-time setup.** The 1.1 GB model is not inside the APK; see the app README.

## 🗺️ Roadmap

- **Field photos** — measure accuracy on real field images and report it next to the lab figure
- **Multi-crop v2 model** — 5 crops, 25 classes (tomato, potato, cotton, maize, grape)
- **Wider pest coverage** — a subset of common pests from IP102
- **Severity v3** — a texture/contrast channel for dark-spot diseases, validated on a larger set
- **Smaller vision model on the phone** — ship the INT8 student, and an ExecuTorch (`.pte`) export of the vision model

## 🌐 Web demo

A zero-install mirror of the vision pipeline: [open the live demo](https://indra-dev404.github.io/KrishiScan-for-ARM-AI-SOC/web-demo/). Model and runtime are bundled with the page (no CDN, no server). It covers diagnosis and a static advisory card only; severity and Llama live in the Android app.

```bash
cd web-demo
python3 -m http.server 8000
# open http://localhost:8000
```
